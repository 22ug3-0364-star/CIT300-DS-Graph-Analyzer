# CIT300 Data Structure & Graph Performance Analyzer

## Project Description
A Java console-based application developed for CIT300 Data Structures and Algorithms (Graded Practical Assignment 2). The system demonstrates arrays, stacks, queues, linked lists, searching algorithms, graph traversal (BFS and DFS) and a performance comparison of algorithms, with input validation and object-oriented design.

## Main System Features
- Array operations: insert, delete, search, display
- Stack operations: push, pop, peek, display
- Queue operations: enqueue, dequeue, peek, display
- Linked List operations: insert, delete, search, display
- Searching: Linear Search and Binary Search with steps and execution time
- Graph operations: add vertex, add edge, display, BFS, DFS
- Performance comparison of algorithms
- Input validation and handling of empty data structures

## Complexity Summary
| Operation | Complexity |
|---|---|
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Linked List insert at end / search / delete | O(n) |
| Stack push / pop / peek | O(1) |
| Queue enqueue / dequeue / peek | O(1) |
| BFS / DFS | O(V + E) |

## How to Run
1. Install JDK 17 or higher (JDK 21 recommended).
2. Clone the repository:
   `git clone https://github.com/22ug3-0364-star/CIT300-DS-Graph-Analyzer.git`
3. Open the project in IntelliJ IDEA or Eclipse.
4. Open `src/Main.java` and click the Run button.
5. Use the main menu (1-9) to select a component.
